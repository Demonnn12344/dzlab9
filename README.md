# Тема 9. Задача А. Вариант 6 — равнобедренный треугольник

## Условие задачи

Написать программу, которая выводит на экран контур равнобедренного
треугольника. Пользователь вводит символ для рисования и высоту треугольника `h`.
Контур включает боковые стороны и основание. Внутри треугольника остаются пробелы.

---

## 1. Идея решения

Треугольник состоит из `h` строк. Если номер строки `i` считать от 0,
перед контуром нужно вывести `h - i - 1` пробелов. После отступа ширина
строки равна `2 * i + 1`.

В каждой строке символ выводится в первой и последней позиции. В нижней
строке символ заполняет все позиции, чтобы получилось основание. При
`h = 1` вершина и основание совпадают, поэтому выводится один символ.

---

## 2. Алгоритм и блок-схема

### Алгоритм

1. Считать символ и высоту `h`. Если высота некорректна или меньше 1, вывести сообщение об ошибке.
2. Для каждой строки `i` от 0 до `h - 1` вывести `h - i - 1` пробелов.
3. Перебрать позиции `j` от 0 до `2 * i` включительно. Вывести символ, если `j == 0`, `j == 2 * i` или `i == h - 1`. В остальных позициях вывести пробел.
4. Перейти на новую строку и повторять шаги 2–3, пока не будут выведены все строки.
5. Завершить программу.

### Блок-схема

~~~mermaid
flowchart TD
    A([Начало]) --> B[/Ввод символа/]
    B --> C{"Символ считан?"}
    C -- Нет --> N([Конец])
    C -- Да --> D[/Ввод h/]
    D --> E{"Высота считана и h >= 1?"}
    E -- Нет --> F[/Сообщение об ошибке/]
    F --> N
    E -- Да --> G["i = 0"]
    G --> H{"i < h?"}
    H -- Нет --> N
    H -- Да --> I["Вывести h - i - 1 пробелов"]
    I --> J["j = 0"]
    J --> K{"j <= 2 * i?"}
    K -- Да --> L{"j = 0, j = 2 * i или i = h - 1?"}
    L -- Да --> P[/Вывести символ/]
    L -- Нет --> Q[/Вывести пробел/]
    P --> R["j = j + 1"]
    Q --> R
    R --> K
    K -- Нет --> S[/Перейти на новую строку/]
    S --> T["i = i + 1"]
    T --> H
~~~
